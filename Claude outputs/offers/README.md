# Шаблон коммерческого предложения MY Avto (Dark Gold)

Скрипт для генерации клиентских коммерческих предложений (КП) в фирменном
стиле сайта my-avto.online — тёмный фон + золотой акцент.

## Файлы

- `generate_offer.js` — генератор на Node.js (библиотека `docx`). Содержит
  готовые хелперы (`darkBand`, `sectionTitle`, `bodyText`, `bullet`, `hr`,
  `specTable`) и палитру бренда — можно скопировать и переписать контент
  под другую модель авто, оставив стиль/структуру без изменений.
- `Geely_Galaxy_M7_Starship_offer.docx` / `.pdf` — готовый пример КП
  (Geely Galaxy M7, комплектация Starship, 星舰版), 2 страницы, с фото
  экстерьера и салона. Можно использовать как референс структуры.
- `m7_photo.png`, `m7_interior.png` — фото автомобиля (экстерьер серого
  цвета и салон/приборная панель), использованные в примере.

## Как использовать для новой модели

1. Скопировать `generate_offer.js` под новым именем (например,
   `generate_offer_<модель>.js`).
2. Заменить контент: название модели/комплектации, спецификации,
   комплектацию, цену и разбивку платежа, фото (см. блок ImageRun).
3. Установить зависимости и сгенерировать:
   ```
   npm install docx
   node generate_offer_<модель>.js
   ```
4. Проверить вёрстку — конвертировать в PDF и посмотреть постранично
   (LibreOffice headless + pdftoppm), прежде чем отправлять клиенту.
