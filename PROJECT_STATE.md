## Что это
Публичный агрегатор компаний по импорту авто в СНГ (Китай, Корея, Япония, США,
ОАЭ, Европа). Сайт: myavto-agregator.ru. Репозиторий: GitHub
`lesnikovmn-svg/myavto-agregator` (публичный).

## Архитектура
Google Sheets (база данных) → Python-скрипты на Маке → генерируют встроенный
JS-массив в `index.html` → git push → GitHub Pages (основной источник) +
VPS REG.ru (зеркало, отдаёт сайт для рунета/Яндекса).

## Инфраструктура
- **Домен**: myavto-agregator.ru, регистратор и DNS — REG.ru.
- **VPS**: REG.ru, IP `89.108.70.185`, Ubuntu, nginx, SSL через certbot
  (автопродление настроено certbot'ом). Раз в 10 минут делает
  `git pull origin main` в `/var/www/myavto-agregator` (cron на самом VPS).
- **GitHub Pages**: остаётся как есть, обновляется автоматически при пуше.
- **Агент и автоматизация** (поиск компаний, обновление сайта) — по-прежнему
  **на Маке**, не на VPS. Работает через `daily_update.sh` + cron
  (`crontab -l` на Маке: `0 8 * * * ~/myavto-agregator/daily_update.sh`).
  Пуш в GitHub — по SSH-ключу, passphrase в Keychain
  (`ssh-add --apple-use-keychain`), поэтому работает без участия человека.

## Ключевые файлы (в папке myavto-agregator)
- `index.html` — сам сайт, один файл (HTML+CSS+JS), данные компаний зашиты
  прямо в JS-массив (генерируется скриптом, руками не редактировать).
- `update_site.py` — тянет данные из Google Sheets, гоняет ЕГРЮЛ-проверку,
  пересобирает `index.html`, коммитит и пушит.
- `company_agent.py` — ищет новые компании (tgstat.ru + DuckDuckGo),
  добавляет строки в Google Sheet. Извлекает ИНН со страниц компаний.
- `verify_egrul.py` — проверка компании по ИНН (ЕГРЮЛ/ЕГРИП). Источник 1 —
  DaData API (нужен токен), источник 2 — egrul.itsoft.ru (на 08.08.2026
  стабильно отдаёт 403, фактически не работает). Результаты кэшируются в
  `egrul_cache.json`.
- `backfill_inn.py` — разовый скрипт, добивает ИНН для старых компаний,
  у которых его не было при первом добавлении.
- `daily_update.sh` — обёртка для cron: агент → update_site → пуш.
- `agent_config.env` — **секреты, в git не попадает** (см. `.gitignore`):
  `GOOGLE_API_KEY`, `SEARCH_ENGINE_ID`, `SHEET_ID`, `DADATA_TOKEN`.
- `credentials.json` — сервисный аккаунт Google (для gspread), тоже в
  `.gitignore`, в git не попадает.
- `egrul_cache.json` — кэш проверок ЕГРЮЛ, **в git попадает** (это ОК,
  не секрет, просто данные).
- `favicon.ico` / `favicon-32.png` / `apple-touch-icon.png` — иконка сайта
  (логотип агрегатора — глобус с машиной, вырезан из полного лого).
  Старый `favicon.svg` (364КБ, чужое фото) больше не используется, но
  оставлен в репозитории (не мешает).

## Данные о компании автора (My Avto, id:1 в каталоге)
Работает с 2015 года (11 лет), ИП сейчас закрыто (работает без формальной
регистрации), привезено 1000+ авто. Это единственная компания, где данные
подтверждены лично владельцем, а не автоматической проверкой.

## Как устроена «честность» сайта
- Зелёный бейдж «✓ В ЕГРЮЛ с {год} года» — показывается ТОЛЬКО если
  `verify_egrul.py` реально нашёл компанию в реестре И она активна (не
  ликвидирована/закрыта).
- Иначе — нейтральный бейдж «✓ Проверена активность» (просто означает, что
  агент нашёл сайт/страницу компании, не более).
- Если у компании 0 отзывов — рейтинг/звёзды не показываются вообще (вместо
  них «Новая в каталоге, отзывов пока нет»), чтобы не рисовать фейковые 4.5.
- Телефоны скрыты за кнопкой «Показать номер» — не палятся в открытую.

## Известные ограничения / открытые вопросы
- Рейтинги/отзывы у ~32 «сидовых» компаний (добавленных до автоматизации) —
  не факт, что реально проверены, точных данных по методике нет (сам автор
  сказал «не помню, надо перепроверять»). Не трогали, т.к. отдельная задача.
- itsoft.ru как источник ЕГРЮЛ фактически не работает (403), держится в коде
  как резерв на случай, если снова заработает.
- 2GIS-карточка компании, Telegram-бот приёма заявок — в планах, не начаты.
- Статья на VC.ru — черновик готов (`vc_ru_article_draft.md`, не в git),
  не опубликована.
- SEO-статья по методике (`seo_kak_vybrat_kompaniyu_importera.md`, не в git)
  — готова, не опубликована/не встроена в сайт.
