# на React/Next.js/Vue отдают обычному requests.get() почти пустой
# каркас (телефон/email/telegram дорисовывает JS уже в браузере), это
# headless-браузер (Chromium через Playwright) как прицельный fallback
# именно для таких сайтов. Как и с tesseract/ffmpeg выше — pip ставит

# "--with-deps" сам подтянет системные библиотеки Chromium через apt —
# без него на голом VPS браузер не запустится (не хватит .so-библиотек).

# rendered() просто напечатает предупреждение и вернёт "" (тот же
# безопасный fallback-принцип, что и у остальных extract_*/fetch_*).
playwright
